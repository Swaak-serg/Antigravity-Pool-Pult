# Antigravity Pool pult

Android-приложение для удалённого управления локальным пулом `ag-pool` на ПК через защищённый облачный туннель: сопряжение по QR-коду, просмотр квот моделей (5ч и неделя), переключение активного аккаунта, управление ротацией и принудительное обновление квот.

Здесь публикуются только собранные APK (раздел Releases). Исходный код в этом репозитории не хранится.
Обновления — через [Obtainium](https://github.com/ImranR98/Obtainium): добавьте ссылку на этот репозиторий.
